# Inglés de hoy

Página personal para practicar inglés todos los días con clips cortos de video, shadowing y Anki (plan de 90 días).

- `index.html`: la página. El progreso se guarda en el navegador (localStorage).
- `videos.json`: los videos de cada semana, cortados en clips, con las frases clave y sus tiempos.

Videos usados con fines de estudio personal. Charla de la semana 1: Curtis "Wall Street" Carroll en TED (TED2016), licencia CC BY-NC-ND 4.0 — ted.com.
